# Hop screenshots

Captured from the actual Hop GUI on macOS ARM64 with Java 21, Apache Hop 2.19.0,
and GeoHop distribution 0.2.1-SNAPSHOT.build.35761791293.1 (22 September 2026).
The screenshots show the pipelines and synthetic data in downloads/vector-formats.

Each format has a pipeline canvas, its actual writer dialog, and metrics from a
successful GUI run (three rows, zero errors). reader.png is shared because every
main pipeline reads the same source layer. The screenshots are cropped native
macOS captures; they are not generated illustrations or reconstructed dialogs.
Some GeoPackage/FileGDB controls have German labels in this plugin build even
when Hop's UI language is English. The tutorials give those visible labels and
the corresponding stored mode names.

Recapture screenshots when settings or plugin dialogs change. Keep configuration
values relative to PROJECT_HOME and omit unrelated desktop/application content.
